# Dataset splits

Questa directory conterrà manifest immutabili per `train`, `validation`, `test` ed `external`.
Lo split è per articolo/progetto, mai per frase, e deve tenere uniti preprint/versione pubblicata,
laboratorio o corresponding author quando possibile, dataset/supplementi collegati e template
sintetico. Synthetic è ammesso soltanto nel train. Non esiste ancora uno snapshot o split
approvato; la directory vuota non dimostra un leakage audit.
