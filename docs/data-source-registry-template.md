# Template registro fonti dati

Creare una copia locale sotto `local-data/metadata/sources/`; non compilare nel
repository pubblico URL riservati, access key, dati personali o note contrattuali
confidenziali.

| Campo | Valore |
|---|---|
| Source ID/versione | `PENDING` |
| Nome e URL primario | `PENDING` |
| Ente/autore responsabile | `PENDING` |
| Descrizione | `PENDING` |
| Accesso/download | `PENDING` |
| Formati e dimensione | `PENDING` |
| Licenza per asset | `PENDING` |
| URL/evidenza della licenza | `PENDING` |
| Usi candidati | analyze / annotate / train / share / redistribute |
| Utilità N-Truth | parser / rule fixture / manual annotation / external validation |
| Privacy/restrizioni | `PENDING` |
| Rischio leakage/contamination | `PENDING` |
| Checksum/retrieval timestamp | `PENDING` |
| Reviewer e disposition | pending / approved_tier_a / rejected |

La licenza della pagina o del repository non va estesa automaticamente ai singoli file.
