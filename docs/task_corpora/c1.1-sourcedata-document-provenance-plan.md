### Provenance granularity vocabulary (required reporting)

```text
ARTICLE | FIGURE | PANEL | SEGMENT | RECORD_FALLBACK | UNKNOWN
```

## Why required

Current entity_roles audit:

```text
groups_crossing_splits: 0
leakage_group_granularity: RECORD_LEVEL_FALLBACK
document_id_present: 0
document_id_missing: 75163
unique_leakage_groups: 75163
```

`groups_crossing_splits=0` is formally true but scientifically uninformative: each record is its own group.

## Investigation findings (2026-08-03)

### Raw HF export on stick (`raw/sourcedata/v2.0.3/{ner,roles_multi}/{split}.jsonl`)

Each line is an object with **only**:

```text
words, labels, is_category, text
```

No `document_id`, `panel_id`, `figure_id`, `pmid`, `doi`, or other paper/family keys in the first 500 train rows (or in the schema of the locked token_classification export).

### Workstream B multitask envelope

`packages/ntruth/data/datasets/sourcedata.py` writes:

```python
document_id = str(rec.get("document_id", ""))
segment_id = str(rec.get("panel_id", ""))
group_id = str(rec.get("document_id", ""))
```

Because raw records lack those fields, all three are empty strings.
`record_id` becomes `sourcedata:{idx}:{split}:{idx}` (line index).

### Alignment

`packages/ntruth/data/alignment.py` joins NER ↔ ROLES_MULTI by:

1. same physical line index within each upstream split file;
2. identical `words` sequence;
3. fail-closed on token or label-length mismatch.

Explicit note in code:

```text
panel_id_field_present: False
stable_across_revisions: False
```

NER and ROLES from the same line index are already paired, but **not** linked to a paper/figure family ID.

### Conclusion

Document-level IDs were **not discarded by an accidental transform step** in the current pipeline: the **locked SourceData token_classification JSONL export simply does not contain them**. Recovery requires a richer upstream source or a verified external join key — not inventing IDs per record.

## Forbidden approaches

- generating a unique `document_id` per record;
- hashing the whole record and calling it document provenance;
- clustering by text similarity and treating clusters as papers without external verification;
- treating record-level fallback as paper-level isolation.

## Implementation plan (future PR)

1. **Inventory alternate SourceData assets**
   - HF dataset configs beyond the locked `token_classification` JSONL
   - Original SourceData / EMBO figure XML or API dumps if license allows
   - Any panel/paper identifiers in companion configs at the same revision

2. **If recoverable IDs exist**
   - map them into multitask envelopes without guessing
   - set `leakage_group` to paper/family ID
   - keep panel ID as segment when available
   - re-emit alignment report with `panel_id_field_present` / document coverage stats

3. **If not recoverable from locked revision**
   - document `PROVENANCE_UNRECOVERABLE_FROM_LOCKED_EXPORT`
   - quarantine or mark `model_use_status=BLOCKED` remains
   - optional: store `words_sha256` + split + line index as **join key only**, not as document_id
   - evaluate re-lock of a richer config under Workstream B process (new Merkle, new revision)

4. **Acceptance**

```text
- document_id or strongest justified family ID populated where supported
- leakage_group_granularity explicitly reported (DOCUMENT | FIGURE_FAMILY | RECORD_FALLBACK)
- zero supported document families crossing model-use partitions (when partitions approved)
- unrecoverable cases quarantined or non-model-eligible
- no synthetic document IDs
- no training
```
