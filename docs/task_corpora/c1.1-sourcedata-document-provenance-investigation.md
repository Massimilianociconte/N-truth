## 4. Join strategies S1–S5 and match counts

Two-pass dict counting; emit ONLY keys with exactly one record-side AND one asset-side match (fail-closed).

| Strategy | Rule | Result |
|---|---|---|
| S1 explicit stable identifier | record carries a stable document key | **impossible** — `document_id_present` = 0 across all 75,163 records |
| S2 official source-record identifier | locked export references upstream record IDs | **impossible** — locked JSONL lines carry only `words/labels/is_category/text`; upstream XML `panel_id` exists but the local side holds no reference to it |
| S3 exact canonical text → unique panel | two-pass counting on canonical raw `text`; emit only keys with exactly 1 record AND exactly 1 upstream panel | **71,183** records get unique PANEL identity (doi + fig_id + panel_id) |
| S4 deterministic annotation tuple | on S3-ambiguous text keys, join (text, sorted entity-span tuple SHA-256) vs upstream (caption, sd-tag entity tuple SHA-256); 1:1 unique only | **+14** records (ambiguous record keys 1,943; tuple resolved 14; still ambiguous 3,966; no asset text 1) |
| S5 composite file-path + line index + words_sha256 | revision-bound alignment key | proves record ↔ upstream `token_classification` file+line at the locked revision; **cannot prove** ARTICLE/FIGURE/PANEL identity; NOT acceptable as document provenance by itself |

Residual after S3+S4:

- **3,965 records — ARTICLE-level deterministic** (`AMBIGUOUS_SINGLE_DOI`): text matches multiple panels, all inside a SINGLE article → DOI provenance is deterministic; panel identity is not.
- **1 record unmatched** (`UNMATCHED_NO_ASSET_TEXT`, train line 17638): no exact caption counterpart in any official asset → no public-asset provenance. No synthetic ID is assigned to it.

Sum check: **71,183 + 14 + 3,965 + 1 = 75,163** exactly.
