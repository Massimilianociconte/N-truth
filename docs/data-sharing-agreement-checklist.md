# Data sharing agreement - checklist

Template operativo, non consulenza legale e non accordo firmato.

- [ ] Parti, referenti istituzionali e titolarita chiaramente identificati.
- [ ] Finalità e usi autorizzati separatamente: `analyze`, `annotate`, `train`, `share`,
  `redistribute`; nessun permesso implicito.
- [ ] Elenco minimo dei file; immagini grezze e dati personali esclusi salvo necessita approvata.
- [ ] Base giuridica/privacy e responsabilita definite, con coinvolgimento DPO quando necessario.
- [ ] IP, licenza di annotazioni, diritto di pubblicare e attribuzione definiti.
- [ ] Accessi, cifratura, localizzazione, backup e sub-responsabili definiti.
- [ ] Retention, review, revoca e cancellazione verificabile definite.
- [ ] Revoca chiarita per snapshot già pubblicati e per versioni future.
- [ ] Divieto di usare external test per training o model selection.
- [ ] Gruppi anti-leakage per articolo/versione, laboratorio, dataset, supplemento e template
  sintetico definiti.
- [ ] Gestione incidenti, ritiro di asset e correzione delle release definite.
- [ ] Diritto di pubblicare soltanto metriche aggregate per dati non pubblici definito.
- [ ] Modalità di riconoscimento/attribuzione e possibilità di embargo definite.
- [ ] Scanner privacy e revisione umana prima di export/share previsti; una copia redatta resta
  separata dalla fonte.
- [ ] Firmatari autorizzati e date di efficacia/scadenza presenti.
