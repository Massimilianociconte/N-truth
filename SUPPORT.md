# Supporto

N-Truth è una baseline di ricerca in sviluppo, non un servizio clinico o una
consulenza statistica.

## Prima di chiedere aiuto

1. leggere [README.md](README.md) e [troubleshooting](docs/troubleshooting.md);
2. eseguire `uv run ntruth version`;
3. riprodurre il problema con una fixture sintetica minima;
4. verificare che `uv run pytest` sia verde sul proprio checkout.

Per bug riproducibili o richieste documentali usare una
[GitHub Issue](https://github.com/Massimilianociconte/N-truth/issues). Non allegare
paper non redistribuibili, dati di laboratorio, sample ID reali, percorsi utente,
credenziali o output contenenti identificatori.

Per vulnerabilità seguire [SECURITY.md](SECURITY.md) e usare una segnalazione privata.
Domande sulla correttezza scientifica di una regola richiedono una review tracciata da
wet-lab expert e biostatistico; una discussione in issue non equivale ad approvazione.
